# 🧠 AI/ML Mini Projects

Welcome to my personal repository of mini projects built while learning Artificial Intelligence and Machine Learning. This repo serves as a **lab notebook**, **portfolio**, and **sandbox** for experiments, whether from university assignments, online courses, research article replications, Kaggle challenges, or just curious tinkering.
___

## 📁 Repository Structure

Projects are organized by **source** and **date**, following this structure:

```
LEARN_ML/
├── university/
├── online-courses/
├── article-replications/
├── kaggle-experiments/
├── personal-experiments/
└── tools-and-snippets/
```

Each project is named using the format:
```
YYYY-MM_project-name-with-hyphens/
```
This helps keep everything in **chronological order**.
